# Articles

### Start here

- [Getting started with
  priogridR](https://christianoswald.github.io/priogridR/articles/getting-started.md):

  Learn the core grid utilities, return types, output helpers, and
  plotting conventions in priogridR.

- [Grid
  foundations](https://christianoswald.github.io/priogridR/articles/grid-foundations.md):

  Convert cells and coordinates, create geometries, validate and
  complete panels, join variables safely, and map results.

- [Grid identifiers and
  neighborhoods](https://christianoswald.github.io/priogridR/articles/grid-utilities.md):

  Create identifier matrices, inspect neighboring cells, and connect
  these utilities to configurable PRIO-GRID geometries.

- [Results, output, and
  visualization](https://christianoswald.github.io/priogridR/articles/results-output-visualization.md):

  Work with structured conversion results, create reproducible project
  paths, write supported formats, and customize PRIO-GRID maps.

- [Choosing a PRIO-GRID conversion
  workflow](https://christianoswald.github.io/priogridR/articles/conversion-workflows.md):

  Choose the appropriate priogridR converter for raster, vector,
  point-event, NetCDF, or geographically indexed tabular data.

### Conversion guides

Detailed workflows for each supported source-data format.

- [Converting point and event
  data](https://christianoswald.github.io/priogridR/articles/pg_from_points.md):

  Aggregate coordinates and point events to PRIO-GRID cells, including
  values, dates, groups, and structural zeros.

- [Converting raster
  data](https://christianoswald.github.io/priogridR/articles/pg_from_raster.md):

  Align static and time-varying rasters to PRIO-GRID and choose suitable
  aggregation, disaggregation, and output options.

- [Converting vector
  data](https://christianoswald.github.io/priogridR/articles/pg_from_vector.md):

  Aggregate point, line, and polygon geometries to PRIO-GRID using
  counts, lengths, areas, coverage, and weighted values.

- [Converting NetCDF
  data](https://christianoswald.github.io/priogridR/articles/pg_from_netcdf.md):

  Select NetCDF variables and layers, handle time and missing values,
  and convert them to PRIO-GRID.

- [Converting geographically indexed
  tables](https://christianoswald.github.io/priogridR/articles/pg_from_table.md):

  Join tabular observations to polygon geographies and transfer totals,
  rates, or constant values to PRIO-GRID cells.
